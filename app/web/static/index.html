这是什么

      
本地的 Qwen-Image-2.1 图像生成与编辑工作台：文生图、多图编辑、渲染队列与图库，全部通过你本机的 ComfyUI 渲染，不联网上传任何内容。


      
快速开始

      
    
        
  • ⚙ 路径里填 ComfyUI 安装目录（如 ~/ComfyUI-Installs/ComfyUI）或运行中的 http 地址——Studio 会自动无头启动它。
    • 
        
  • 写提示词 → 选比例 → 点「生成」。模型第一次加载要几分钟，之后常驻缓存，出图很快。
    • 
        
  • 导入图片：把图片拖进右侧参考图区，或点「从图库选择」。有参考图即进入「编辑」模式。
    • 
      


      
操作提示

      
    
        
  • ↻ 刷新：确认后清空全部参考图与提示词，参数恢复默认。成片不受影响。
    • 
        
  • 右键菜单：成片与图库中的图片，右键即可「用作参考图」「复用设置」「打开」「删除」。复用设置会把这张成片当时用的参考图一并恢复（文件还在时）。
    • 
        
  • 单击选中，双击放大：成片条里单击选图进预览，双击直接全屏看图。
    • 
        
  • 图库：分「输出」与「输入」。右下角显示 Output、Input 与储存目录，可「在访达打开」；输入页的图也能右键删除。
    • 
        
  • 文件命名：图库显示的名字就是 Output / Input 文件夹里的文件名。
    • 
        
  • 提示词里输入 @ 引用参考图，按顺序写成 <image1>、<image2>。
    • 
      


      
文件储存

      
所有图片与数据都在用户目录下：

      
~/Qwen Image Studio/
├── Input/    导入的参考图
├── Output/   生成的成片
└── 储存数据（会话、缩略图、日志）

      
每张图片只存一份——参考图在 Input/，成片在 Output/，软件直接以这两个文件夹为存储。删除该目录即恢复出厂。服务器只监听 127.0.0.1，什么都不上传。删除是双向同步的：软件里删掉成片或参考图，Input/、Output/ 里的文件随之删除；反过来在访达里删掉文件，下次打开图库时对应条目也会自动清除。


      
常见问题

      
    
        
  • 「ComfyUI has no Qwen-Image model」：填的实例看不到模型——填安装目录让 Studio 自己启动。
    • 
        
  • 首次渲染慢：加载约 15 GB 权重属正常，之后模型常驻缓存。
    • 
        
  • 参数是否生效：看渲染日志的 graph injected 一行。
    • 
      

    


    

      
What this is

      
A local workbench for Qwen-Image-2.1: text-to-image, multi-image editing, a render queue and a gallery — everything renders through your local ComfyUI, nothing is sent anywhere.


      
Quick start

      
    
        
  • Set the ComfyUI install directory (e.g. ~/ComfyUI-Installs/ComfyUI) or a running http URL under ⚙ Paths — the studio starts it headless.
    • 
        
  • Write a prompt → pick a ratio → Generate. The first render loads the models (minutes); afterwards they stay cached.
    • 
        
  • Import images: drop them into the references area, or pick from the gallery. References switch you to Edit mode.
    • 
      


      
Operating tips

      
    
        
  • ↻ Reset asks for confirmation; confirming clears every reference and the prompt and restores the defaults. Takes are untouched.
    • 
        
  • Right-click a take or a gallery image for “Use as reference”, “Reuse settings”, “Open” and “Delete”. Reuse brings the references the take was made from back with it (while their files exist).
    • 
        
  • Single click selects, double click enlarges: in the takes strip a click shows the take, a double click opens it full screen.
    • 
        
  • Gallery: Output and Input tabs. The bottom-right corner shows the Output, Input and Storage folders, with “Open in Finder”; Input items can be deleted from their right-click menu.
    • 
        
  • Naming: gallery names are the file names in the Output / Input folders.
    • 
        
  • Type @ in the prompt to name a reference image, written as <image1>, <image2>…
    • 
      


      
Files

      
Every image and all data live in your home folder:

      
~/Qwen Image Studio/
├── Input/    imported references
├── Output/   finished takes
└── studio data (sessions, thumbnails, logs)

      
Every image is stored exactly once — references in Input/, takes in Output/; the folders are the storage. Delete that folder for a factory reset. The server listens on 127.0.0.1 only — nothing leaves your machine. Deletion syncs both ways: removing a take or a reference in the studio removes its file from Output/ or Input/; removing the file in Finder removes the matching gallery item or reference entry the next time the gallery loads.


      
Questions

      
    
        
  • “ComfyUI has no Qwen-Image model”: that instance can't see the weights — set the install directory instead.
    • 
        
  • First render is slow: loading ~15 GB of weights is normal; afterwards they stay cached.
    • 
        
  • Checking that a setting took effect: the graph injected line in the render log.
